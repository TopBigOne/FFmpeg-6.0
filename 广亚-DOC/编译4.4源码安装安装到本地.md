# 编译 FFmpeg release/4.4 并安装到本地

目标：在 Mac 电脑（M 系列芯片）上，编译分支 `release/4.4`，并安装到 `/usr/local/ffmpeg/4.4`。

---

## 1. 安装依赖

一下子安装3个包：

```bash
brew install nasm yasm pkg-config
```

## 2. 配置（指定安装路径）

```bash
cd /Users/dev/Documents/AV/FFmpeg-6.0

./configure \
  --prefix=/usr/local/ffmpeg/4.4 \
  --enable-shared \
  --disable-static \
  --enable-gpl \
  --enable-version3 \
  --enable-nonfree \
  --enable-debug \
  --disable-optimizations \
  --disable-stripping \
  --disable-x86asm
```

常用可选项：

| 选项 | 说明 | 前置依赖 |
|------|------|----------|
| `--enable-libx264` | H.264 编码 | `brew install x264` |
| `--enable-libx265` | H.265 编码 | `brew install x265` |
| `--enable-libfdk-aac` | AAC 编码 | `brew install fdk-aac` |
| `--enable-videotoolbox` | macOS 硬件加速 | 无（系统自带） |
| `--disable-doc` | 跳过文档，加快编译 | 无 |

## 3. 编译

```bash
cd /Users/dev/Documents/AV/FFmpeg-6.0
make -j$(sysctl -n hw.logicalcpu)
```

- **`make`** — 执行编译，读取 `Makefile` 开始构建
- **`-j`** — 允许并行编译，同时跑多个编译任务
- **`$(sysctl -n hw.logicalcpu)`** — 动态获取当前机器的逻辑 CPU 核心数（M 系列通常是 8、10、12）
- 合起来等价于 `make -j10`（以 10 核为例），充分利用多核，比单线程快 5~8 倍



## 4. 安装

```bash
cd /Users/dev/Documents/AV/FFmpeg-6.0
sudo make install
```
-  **`make install`**  — 把编译好的产物复制到 --prefix 指定的目录：

安装完成后的目录结构：

```
/usr/local/ffmpeg/4.4/
  bin/        ffmpeg, ffprobe, ffplay
  lib/        动态库 (.dylib)
  include/    头文件
  share/      man pages
```

## 5. 验证

```bash
/usr/local/ffmpeg/4.4/bin/ffmpeg -version
```

---

> **多版本共存提示**：如需同时保留多个 FFmpeg 版本，只需对不同版本使用不同的 `--prefix`，各版本互不干扰。
